# Stack Sans fonts

Self-hosted, unmodified variable fonts by Koto, downloaded from the official
[Google Fonts repository](https://github.com/google/fonts) on November 9, 2026.

- `StackSansNotch-Variable.ttf`: **Stack Sans Notch**, normal style, weights 200–700.
  Source: `ofl/stacksansnotch/StackSansNotch[wght].ttf`.
- `StackSansText-Variable.ttf`: **Stack Sans Text**, normal style, weights 200–700.
  Source: `ofl/stacksanstext/StackSansText[wght].ttf`.

Both families are licensed under the SIL Open Font License 1.1. Their accompanying
`*-OFL.txt` files preserve the copyright and license notices. Upstream project:
https://github.com/DylanYoungKoto/Stack-Sans.

Detour uses Notch for headings and callouts, and Text for body copy and controls.
